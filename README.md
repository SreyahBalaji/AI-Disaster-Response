# AI-Driven Disaster Response and Dynamic Resource Allocation

Research prototype for intelligent disaster-resource allocation using graph-based learning, multi-agent reinforcement learning, fairness-aware decision making and federated learning.

## Experimental Scenario

Kerala flood disaster response using a semi-synthetic experimental environment.

## Core Components

- Crisis-report NLP
- Graph Attention Network (GAT)
- Multi-Agent Reinforcement Learning (MARL)
- PPO/MAPPO
- Fairness-aware resource allocation
- Federated Learning
- FedAvg
- Dynamic resource reallocation
- GIS-based visualization

## Data Strategy

The project combines verified historical and geographic data with explicitly simulated operational resource data.

Real/historical sources include:

- Kerala State Disaster Management Authority
- HumAID
- Government demographic datasets
- OpenStreetMap

Operational variables such as resource demand, centre inventory and dynamic disruptions are simulated and documented separately.
